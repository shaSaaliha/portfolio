AI Knowledge Assistant for Industrial Maintenance

Contributed to an AI knowledge platform that turns crane maintenance manuals into a Neo4j knowledge graph and answers technicians' questions with retrieval-augmented generation (RAG) on Azure AI Search, deployed with Docker. I migrated the web app from Streamlit to React and kept extending it. I also enhanced the Microsoft Teams assistant that technicians can ask by text or voice: when the AI isn't confident in an answer, it routes the question to a subject-matter expert and returns their reply in the same chat.

AI UX Insights Agent

Designed and built an AI-powered UX analytics feature that connects Microsoft Clarity to an internal delivery platform. It automatically finds problem pages, such as rage clicks, dead clicks and script errors, and pairs each one with the session recording of the user's journey. I developed an LLM agent with the Model Context Protocol (MCP), Python, FastAPI and PostgreSQL that explains the likely root cause of each issue and suggests clear next steps. It also ranks issues by priority, creates backlog tasks automatically and strips out personal data first, so developers can go straight to the fix instead of spending hours investigating.

Jev Model Evaluation

Evaluated Jev, TypeSafe's typed-judgment AI model, for routing service request tickets to the right service catalog item and group, comparing it with Claude Sonnet, Claude Haiku, an open-weight model and rule-based baselines. I built a Python evaluation pipeline that logs every call's predictions, confidence, tokens, latency and cost to SQLite and generates reports from them. On an 80-ticket test set, Jev reached 95.0% accuracy versus 92.5% for Claude Sonnet, at about 1/73 of the cost and about 12× lower latency (130 ms vs. 1,560 ms).

Salesforce Agentforce Sales Agent

Designed and built a proof of concept Salesforce Agentforce Sales Agent for the company website that turns passive website traffic into booked meetings in real time. It qualifies inbound leads, answers questions about the company's services and schedules meetings, reducing reliance on static lead forms. I grounded its answers in verified company data by configuring Salesforce Data 360 and RAG over curated knowledge bases, and built custom Salesforce Flows and Prompt Templates that create Lead records, assign follow-up tasks to sales reps and book meetings directly. I also defined the agent's topics, natural-language instructions and guardrails, and customized the chat UI for a smooth conversation and handoff to sales representatives.
